窗帘竖向1-2生产图工具 V2

【核心逻辑】
- 只允许竖向顺序拼接: 单元一 → 单元二 → 单元一 → 单元二
- 每个单元为完整竖版图
- 禁止左右并排
- 禁止中线裁切
- 输出必须是竖向长图

【使用方式】
1) 双击运行 EXE: dist/窗帘竖向1-2生产图工具V2.exe
2) 在 GUI 选择:
   - 单元一图片
   - 单元二图片
   - 输出文件夹
   - DPI(150 或 300)
   - 重复次数(2/4/6/8/10)
3) 点击“生成生产图”

【输出文件】
- 竖向1-2生产图.tif （内含 DPI 元数据）
- 预览图.png
- 参数记录.txt

【错误处理】
- 弹窗提示错误
- 同时写入 logs/error.log

【EXE 打包】
- 双击 build_exe.bat 自动安装依赖并执行 PyInstaller
