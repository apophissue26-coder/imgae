窗帘印花裂变生产系统 V3（框架版）

流程：上传原图 -> 自动分析 -> 提取印花 -> 三方向裂变 -> 选方案 -> 生成展示图/生产图 -> 导出参数记录。

三方向裂变：
1) 不改形改色
2) 不改色改形/元素
3) 不改风格重创

生产规则（默认）：
- 竖向 1→2→1→2
- 每层完整单元
- 禁止左右并排
- 禁止中线裁切

输出：
- output/showcase/*.png（约6张展示图）
- output/production/竖向1-2生产图.tif
- output/参数记录.txt

可扩展接口：OpenAI API / ComfyUI / 本地模型（当前为占位接口，未写死模型）。

打包：双击 build_exe.bat
目标：dist/窗帘印花裂变生产系统V3.exe
